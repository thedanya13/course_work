# Этап 2. Разработка базового функционала

## 1. Инициализация проекта

Виртуальное окружение и зависимости настроены. Конфигурация скрыта в `.env`:

```
SECRET_KEY=...
DATABASE_URL=postgresql://...
ENCRYPTION_KEY=...
```

Используется `python-dotenv` для загрузки переменных.

## 2. Базовая логика (CRUD через ORM)

Реализованы основные операции с использованием Flask-SQLAlchemy:

- **Регистрация и вход** (`/register`, `/login`) — параметризованные запросы через ORM, SQL-инъекции исключены.
- **Каталог преподавателей** (`/tutors`) — просмотр и фильтрация.
- **Личный кабинет** (`/profile`) — редактирование профиля.
- **Запись на урок** (`/book/<tutor_id>`) — создание записи в таблице `lessons`.
- **Календарь уроков** (`/calendar`) — просмотр расписания с FullCalendar.
- **Чат** (`/chat/<lesson_id>`) — обмен сообщениями между учеником и репетитором.
- **Отзывы** (`/reviews/<tutor_id>`) — публикация и просмотр отзывов.
- **Оплата** (`/pay/<lesson_id>`) — проведение платёжной транзакции.

## 3. Поиск преподавателя

Реализован через GET-параметры на `/tutors`:
- Фильтрация по предмету (`ilike` — регистронезависимый поиск).
- Фильтрация по максимальной цене.

```python
if subject:
    query = query.filter(TutorProfile.subject.ilike(f'%{subject}%'))
if max_price:
    query = query.filter(TutorProfile.hourly_rate <= float(max_price))
```

## 4. Видеосвязь (Jitsi Meet)

При создании урока генерируется уникальное имя комнаты:

```python
room_name = f"tutor-platform-{secrets.token_hex(8)}"
```

На странице `/video/<lesson_id>` встраивается iframe Jitsi Meet:

```html
<iframe src="https://meet.jit.si/{{ room }}#config.prejoinPageEnabled=false" ...></iframe>
```

Доступ к странице разрешён только участникам урока (проверка на сервере).

## 5. Календарь уроков

На странице `/calendar` отображаются:
- **FullCalendar** — интерактивный календарь с событиями (месяц/неделя/список).
- Таблица с кнопками: Видео / Чат / Оплатить.

## 6. Заполнение БД тестовыми данными

Скрипт `seed_db.py` создаёт не менее 5000 записей в таблице уроков (Faker).

## 7. Пользовательский интерфейс

Веб-клиент разработан на Bootstrap 5 с адаптивной вёрсткой.
Все страницы: главная, регистрация, вход, каталог, профиль, чат, видео, оплата, отзывы, админ-панель.
